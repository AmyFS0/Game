# NEON RIFT

Prototipo jugable de shooter arcade futurista creado con HTML5 Canvas, CSS y JavaScript.

## Cómo jugar

1. Abre `index.html` en tu navegador, o usa la extensión Live Server en VS Code.
2. Pulsa **START MISSION**.

## Controles

- `WASD`: mover a Nova
- `Mouse`: apuntar
- `Click`: disparar
- `Shift`: correr
- `1`, `2`, `3`: cambiar arma
- `Space`: Quantum Dash
- `Q`: Energy Shield
- `E`: Overcharge

## Prototipo incluido

- 1 personaje: Nova
- 1 mapa: Neon City
- 3 armas
- 3 tipos de enemigos
- 2 habilidades activas + dash
- Mini jefe Rift Warden
- 3 oleadas
- Sistema de vida y energía
- Rift Cores coleccionables
- Puntuación y contador de eliminaciones
- Pantallas de inicio, victoria y derrota
- HUD futurista
- Partículas, impactos, glow y efectos de energía

## Tecnología

No requiere librerías de juego ni instalación de dependencias. El prototipo usa Canvas 2D y JavaScript puro para que sea fácil de ejecutar, modificar y publicar con GitHub Pages.
